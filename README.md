# Pie Menu 🎛️

마우스 커서 위치에서 편리하게 다양한 생산성 도구 및 매크로를 실행할 수 있는 macOS 전용 원형 팝업 메뉴 어플리케이션입니다.

## 주요 기능

1. **Option(⌥) 키 더블 탭 단축키**: 
   - 전역 어디서든 Option 키를 두 번 연속 탭하여 마우스 커서 주변에 원형 파이 메뉴를 즉시 팝업합니다.
2. **앱별 자동 프로필 전환**:
   - 현재 활성화된 전면 앱(Frontmost App)을 감지하여 해당 앱에 맞춤 설정된 프로필이 자동으로 선택되어 나타납니다.
3. **설정 창 단순 숨김 기법 (팝업 방식)**:
   - 설정 창이 닫힐 때 앱 전체가 강제 종료되지 않도록 윈도우 인스턴스를 유지하여 팝업과 같이 작동하게 창 수명 주기를 제어합니다.
4. **다중 프로필 관리 및 좌우 전환**:
   - 무제한 프로필 추가/삭제를 지원하며, 설정 창이나 파이 메뉴 창에서 휠 스크롤 및 키보드로 편리하게 전환할 수 있습니다.
5. **다양한 동작 실행 백엔드**:
   - **Command (쉘 명령어)**: zsh를 활용한 시스템 스크립트 실행
   - **Open App (앱 실행)**: 번들 ID 또는 파일 경로를 이용한 직접 앱 구동
   - **Shortcut (단축키 모의 입력)**: `CGEvent`를 사용한 가상 키보드 입력 매크로 (예: `Cmd+C`, `Shift+Cmd+T`)
6. **앱 선택 다이얼로그 편의 기능**:
   - 설정 창에서 번들 ID를 수동 타이핑할 필요 없이, 폴더 버튼을 클릭해 파일 창에서 앱을 선택하면 자동으로 번들 ID를 파싱해 주는 UX 보완.

## 설치 및 구동 가이드

### 1. 요구사항
- macOS Ventura 13.0 이상 권장
- **손쉬운 사용(Accessibility) 권한 허용**: 글로벌 단축키 모니터링 및 가상 키 입력을 위해 반드시 권한 승인이 필요합니다. (첫 실행 시 안내 창이 팝업됩니다.)

### 2. 빌드
터미널을 열고 워크스페이스 디렉토리에서 아래 스크립트를 구동하여 빌드합니다.
```bash
./build.sh
```
성공하면 워크스페이스 폴더에 `PieMenu.app` 번들이 성공적으로 생성 및 서명됩니다.

### 3. 실행 및 종료
- **실행**: 생성된 `PieMenu.app`을 실행하거나 터미널에서 `./PieMenu.app/Contents/MacOS/PieMenu`를 띄워 구동할 수 있습니다.
- **종료**: 상단 시스템 메뉴 바의 🎛️ 아이콘을 클릭하고 **Quit Pie Menu**를 누르거나, 앱 포커스 상태에서 `Cmd+Q` 단축키를 눌러 완전히 종료합니다.
